# TERRA LAPTOP

A C# console-based game developed for Hack Club Terra.

## Requirements
- .NET SDK compatible with the project file.

## How to run
1. Install the .NET SDK.
2. Open a terminal in this folder.
3. Run:

   dotnet run

- # TERRA LAPTOP — Shopping Simulator

TERRA LAPTOP is a console-based shopping game built with C# and .NET 10. Players act as customers in a virtual store, browse and search the product catalog, explore daily offers, manage a shopping cart, use coupons, stay within a budget, earn loyalty points, and complete purchases. The game also includes a change-making minigame.

## Features

- Browse and search products.
- View daily offers and discounts.
- Add and remove products from the shopping cart.
- Manage a limited budget.
- Apply coupons and earn loyalty points.
- Complete purchases and update inventory.
- Play a change-making minigame.

## How to play on Windows

1. Open the project's GitHub Releases page.
2. Download `TERRA LAPTOP.exe` from the latest release.
3. If Windows displays a security warning for an unrecognized publisher, verify that the file came from this project's official GitHub Release before deciding whether to run it.
4. Double-click the downloaded executable to start the game.
5. Follow the console prompts and enter the menu option you want.

The published Windows x64 executable is intended to run without requiring a separate .NET installation.
